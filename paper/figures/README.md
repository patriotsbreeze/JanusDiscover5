# Figures Directory

Place all figure PDFs here before compiling `manuscript.tex`.

## Required files

| File | How to generate |
|---|---|
| `workflow_overview.pdf` | Create manually: flowchart of the 5-panel UI workflow (see paper/README.md). Recommended tools: draw.io → Export as PDF, or Inkscape. |
| `lbdd_results.pdf` | 2×2 composite of ABL1 LBDD figures from JanusDiscover output (see paper/README.md § Step 6). |
| `sbdd_results.pdf` | 2+3 composite of ABL1 SBDD figures. |
| `md_results.pdf` | 2×3 composite of ABL1 MD figures. |

## Naming for Supporting Information

Figures S1–S3 (EGFR and CDK2 LBDD) and S4–S8 (SBDD + MD) can be
individual PNGs uploaded as supplementary files to ACS Paragon Plus;
they do not need to be compiled into the LaTeX PDF.
